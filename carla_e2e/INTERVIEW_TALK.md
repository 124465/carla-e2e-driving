# 面试讲稿：CARLA 端到端模仿学习自动驾驶

> 用法：左边是面试官常问的问题，右边是「标准答 + 进阶答」。先把标准答说顺，再补进阶答显深度。
> 口诀：先一句话结论 → 展开做法 → 讲权衡（pros/cons）→ 抛下一步（体现主动思考）。

---

## Q1. 你这个项目做了什么？一句话介绍
**标准答**：用 CARLA 仿真器采集 autopilot 专家轨迹，训练一个轻量 CNN（图像→转向/油门/刹车）的端到端驾驶策略，再用闭环评测看它能不能自己开完路线。
**进阶答**：本质是用**行为克隆（Behavior Cloning）**做模仿学习，属于离线 IL；对比 RL 它不需要设计奖励函数、训练快，代价是会有分布漂移。

---

## Q2. 为什么选端到端，而不是模块化（感知-预测-规划-控制）？
**标准答**：端到端把感知和控制塞进一个网络，**少手工假设、能直接从数据学隐式表征、迭代快**，适合快速验证。模块化每一步可解释、好定位 bug、符合车规安全，但模块接口要人手设计、误差会逐级累积。
**进阶答**：真实量产一般走模块化（可解释 + 安全可验证）。但端到端近期靠大模型表征（如 Lingo-1 / 端到端占用网络）又火了。我的设计是**先端到端出 demo，再叠可解释中间表征**（如 BEV 分割作辅助监督），兼顾两者。

---

## Q3. 行为克隆最大的问题是什么？你怎么解决？
**标准答**：**分布漂移 / covariate shift**——专家数据只覆盖"好状态"，策略一旦偏一点就进入训练分布外的状态，误差累积 → 撞车（compounding error）。
**进阶答（我的缓解，按 README 落地）**：
1. **DAgger**：用当前策略采样状态，让专家在这些状态上补标签，使训练分布覆盖"坏状态"；
2. **训练加噪 / 域随机化**：多 town、多天气、给观测加噪声，提升鲁棒性；
3. **损失加权**：转向误差权重更高（base.yaml 的 loss_weights）；
4. **闭环评测**：不只看离线 MSE，还看实际驾驶分。

---

## Q4. 你的网络结构？为什么这么小？
**标准答**：TinyDrivingNet，5 层 CNN 提取特征 + 两个全连接头，输出 (steer, throttle, brake)。steer 无界（env 里 clip 到 [-1,1]），throttle/brake 过 sigmoid 锁在 [0,1]。
**进阶答**：受限于 **GTX 1650 4GB**，必须离屏 + 160×80 低分辨率 + 小模型。工业上会用 ResNet/ConvNeXt 骨干 + 多相机 BEV 融合 + Transformer 时序（加历史帧/速度作额外输入）。这里用历史帧和速度（info 里有 speed）是天然下一步。

---

## Q5. 你用什么指标评价？
**标准答**：闭环看三类——**路线完成率(Route Completion %)、驾驶分(Driving Score)、违规率**(碰撞/闯红灯/超速)。离线训练看带权 MSE。
**进阶答**：对齐 CARLA Leaderboard 口径：Driving Score = Route Completion × 违规惩罚。比起开环 MSE，闭环指标才真说明泛化——BC 常开环低误差但闭环很快撞。

---

## Q6. 怎么处理 Sim-to-Real？
**标准答**：**域随机化**——随机化光照/天气/传感器噪声/CAMERA 内外参/车辆动力学参数，让策略对现实扰动不敏感。
**进阶答**：还可以 (a) 用真实数据 finetune 感知骨干；(b) 接 ROS2 把模型封成节点、订阅真实 `/camera` 话题（我工作区已有 yolo_detector / follower_robot，可复用）；(c) 系统辨识补偿动力学差异。

---

## Q7. 如果给你更多时间/资源，怎么提升？
**标准答**（按优先级，体现规划力）：
1. **DAgger** 在线修正分布漂移（最关键）；
2. 加 **BEV 多传感器融合**（相机+LiDAR）；
3. 从 BC 升级到 **RL 微调 / 扩散策略**处理多模态驾驶（并道有左右两种合理动作，BC 会"平均"成撞）；
4. 时序建模（GRU/Transformer + 速度/历史帧输入）；
5. 封 ROS2 节点 + 真机/更好的仿真 (CARLA Town10HD, highway)。

---

## Q8. 行为克隆和 DAgger 的数学直觉？
**标准答**：BC 学 π(a|s) ≈ 专家分布，假设 i.i.d.（实际状态分布随策略漂移，不成立）。DAgger 迭代：π_θ 采数据 → 专家标 → 重新训练，使数据分布逼近 π_θ 的实际访问分布。
**进阶答**：可提 **DAgger 的样本复杂度下界** 和 **交互成本** 是落地难点；工业上常用"采样+远程接管标"近似。

---

## Q9. 多模态动作问题（经典坑，常被追问）
**标准答**：BC 用 MSE 会"平均"多个合理动作（如并道左右），产出危险的中间动作。解法：用 **分类头 / GMM / 扩散策略** 建模多模态。
**进阶答**：扩散策略(2023)在机器人操作火，自动驾驶里也用扩散/流匹配生成多模态轨迹，比单点回归稳。

---

## Q10. 工程与部署
**标准答**：训练用 PyTorch，闭环用 CARLA Python API（同步模式 20Hz）。已做**离屏渲染**适配 4GB 显存。
**进阶答**：可导出 ONNX → TensorRT 部署；量化/蒸馏缩小模型；ROS2 节点化（rclpy 订阅图像、发布 VehicleControl）。
